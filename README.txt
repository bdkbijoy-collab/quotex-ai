QUOTEX AI PWA — iPhone starter

IMPORTANT:
- This is a visual/demo PWA starter only.
- It does NOT connect to Quotex, read its screen, fetch OTC prices, or generate real trading signals.
- Demo button intentionally displays WAIT.
- No trade execution is included.

To publish:
1. Upload the contents of this folder to a static HTTPS hosting provider (for example, a static site host).
2. Open the published HTTPS address in Safari on iPhone.
3. Tap Share -> Add to Home Screen -> Add.
4. Launch QUOTEX AI from the Home Screen.

Do not upload passwords, Quotex login details, API keys, or personal account information.
